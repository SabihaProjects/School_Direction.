# 🏫 School Direction – A Real World School Navigation Project

> **A small initiative to solve a real problem in my school through structured information and thoughtful design.**

## 📌 About the Project

School Direction is a school navigation and room directory project created for **S.K.V. Radhey Shyam Park, Delhi**, a government school.

This project was developed when I was in **Class 10**, with the aim of making it easier for students, visitors, parents, and staff to identify different classrooms, offices, laboratories, and facilities within the school building.

Instead of leaving room locations difficult to identify, I organized the available information into a clear and structured directory based on room numbers, blocks, floors, and room names.

## 🎯 Project Objective

The primary objective was to make school navigation simpler and more convenient by providing an organized reference for locating different rooms and facilities.

## ✨ Key Highlights

- Organized school room directory
- Room number identification
- Block-wise classification (Block A & Block B)
- Floor-wise room organization
- Classroom and laboratory listings
- Administrative office information
- Easy-to-understand visual layout

## 🏢 Project Coverage

The directory covers multiple floors of the school's old building, including:

- Ground Floor
- First Floor
- Second Floor
- Third Floor

It includes classrooms, administrative offices, laboratories, staff rooms, and other school facilities.

## 💡 The Idea Behind It

As a student, I wanted to apply my skills to something meaningful instead of limiting my learning to assignments and theoretical work.

This project was an attempt to identify a practical problem in my own school environment and create a simple, organized solution that could be useful to others.
